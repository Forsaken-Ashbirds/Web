# Forsaken Ashbirds Web

Offizielle Website der Forsaken Ashbirds – umgesetzt mit SvelteKit und auf **Bun** als Paketmanager und Runtime ausgerichtet.

## Entwicklung

Installiere die Abhängigkeiten mit Bun:

```bash
bun install
```

Starte danach den Entwicklungsserver:

```bash
bun run dev
```

## Qualitätssicherung

```bash
bun run check
bun run lint
bun run test
```

## Produktion

Erstelle einen Produktions-Build mit:

```bash
bun run build
```

Zum lokalen Prüfen des Builds:

```bash
bun run preview
```
